# EmergencyLink 使用说明书

## 1. 软件文件

编译后的程序位于：

```text
dist\EmergencyLink.exe
```

同一个 exe 同时支持四种身份：

- 管理者
- 主办方
- 选手-比赛
- 选手-队友

打开软件后会先进入角色选择界面。选择角色后，主界面只展示该角色需要使用的功能。

其中 `选手-比赛` 和 `选手-队友` 不会展示本机服务器配置区域，避免比赛电脑界面过重。

## 2. 部署模式

### 模式 A：主办方电脑兼服务器

适合常规比赛现场。

主办方电脑负责：

- 启动本地服务器
- 创建房间
- 切换比赛阶段
- 审批正式连麦请求
- 扣减连麦次数

其他电脑连接主办方电脑显示的服务器地址。

### 模式 B：管理者电脑兜底服务器

适合主办方不熟悉软件，或需要技术人员统一控场时使用。

管理者电脑负责：

- 启动本地服务器
- 创建房间
- 配置次数和批次时间
- 切换比赛阶段
- 查看全量日志
- 必要时代替主办方审批

主办方电脑只需要作为“主办方”连接房间并审批请求。

## 3. 启动服务器

在需要作为服务器的电脑上打开 `EmergencyLink.exe`，先选择 `主办方` 或 `管理者`。

在“本机服务器”区域填写：

- 房间名
- 房间密码
- 端口，默认 `5050`
- 连麦次数，默认 `3`
- 同批时间，默认 `30` 秒

然后点击其中一个按钮：

- 主办方角色：`启动服务器并以主办方加入`
- 管理者角色：`启动服务器并以管理者加入`

启动成功后，界面会显示本机服务器地址，例如：

```text
192.168.1.20:5050
```

同时会显示开发者 API 地址，例如：

```text
http://127.0.0.1:5051/status
```

如果在其他电脑上查询，把 `127.0.0.1` 换成服务器电脑 IP。

服务器启动后，房间名、密码、端口等启动参数会锁定。需要修改房间名或密码时，请先点击 `停止服务器`，修改后重新启动服务器。

其他电脑连接时需要填写这个地址、端口、房间名和房间密码。

如果其他电脑无法连接，请检查：

- 所有电脑是否在同一个局域网
- Windows 防火墙是否允许该程序或端口通信
- 填写的 IP、端口、房间名、密码是否一致

## 4. 主办方/管理者使用说明

主办方或管理者加入房间后，主要使用“管理/审批”页。

### 阶段切换

可切换四个阶段：

- 准备中
- 赛前测试
- 比赛中
- 结束比赛

规则：

- 赛前测试阶段允许测试提醒，不扣次数。
- 比赛中关闭测试通讯，只允许正式告警。
- 结束比赛后不应再发起新提醒。

### 配置调整

可随时调整：

- 连麦次数
- 同批时间

调整后点击 `应用配置`。

同批时间用于合并队友短时间内的重复提醒。例如设置为 30 秒时，同一目标选手在 30 秒内收到的同类提醒会合并为同一批次，但会再次触发动画和声音。

### 正式请求和扣次

比赛中，队友发起正式告警后，主办方/管理者会在“提醒批次”列表中看到请求。

同时，主办方/管理者电脑会弹出置顶提醒窗，显示目标选手、发起人、剩余次数和是否超额。点击 `查看审批` 会回到主窗口的审批页。

选择请求后点击：

```text
同意选中正式请求
```

扣次规则：

- 选手回执正式请求后，系统立即结算一次连麦额度。
- 剩余次数大于 0：已用次数 +1，剩余次数 -1。
- 剩余次数等于 0：记录为超额连麦，剩余次数保持 0。
- 主办方/管理者同意该请求时不会重复扣减。

如果管理者审批，会在日志中记录为“管理者代审批同意”。

## 5. 选手-比赛使用说明

选手电脑打开 `EmergencyLink.exe`，先选择 `选手-比赛`。进入后只会看到加入房间和选手端功能，不会显示服务器配置。

在“加入通讯房间”区域填写：

- 服务器地址
- 端口
- 房间名
- 房间密码
- 显示名称
连接成功后可进入“选手端”页。

比赛时建议：

- 主窗口可以最小化。
- 保留透明置顶悬浮件。
- 悬浮件可以拖动到合适位置。
- 悬浮件边缘可以拖动调整大小。
- 无提醒时悬浮件不会闪烁，会显示当前阶段和剩余连麦次数。
- 收到提醒后点击悬浮件下方的 `已收到` 按钮发送回执。

提醒样式：

- 准备中：灰蓝色常态。
- 测试提醒：蓝色/黄色闪烁 + 声音。
- 正式告警：红色闪烁 + 声音。
- 超额紧急请求：红色闪烁，并显示超额提示。

## 6. 选手-队友使用说明

队友电脑打开 `EmergencyLink.exe`，先选择 `选手-队友`，然后在“加入通讯房间”区域填写连接信息。

连接后进入“队友端”页。

操作步骤：

1. 选择目标选手。
2. 赛前测试阶段点击 `确认发送测试提醒`。
3. 比赛中点击 `确认发起正式告警`。
4. 弹出二次确认窗口后，再点击确认。

队友端不能输入自由文本，只能触发预设提醒。

## 7. 日志

日志文件保存在 exe 同级目录的：

```text
Data\audit-yyyyMMdd.log
```

日志会记录：

- 服务器启动
- 成员加入/离线
- 阶段切换
- 配置调整
- 测试提醒
- 正式告警
- 提醒合并
- 选手回执
- 主办方同意
- 管理者代审批
- 超额批准

管理者/主办方端的日志区会在新增日志时自动滚动到最新内容，也可以用鼠标滚轮回看历史。

## 8. 开发者 API

本机服务器启动后会同时启动一个只读状态 API。默认情况下，如果通讯端口是 `5050`，API 端口通常是 `5051`。

PowerShell 查询：

```powershell
Invoke-RestMethod http://127.0.0.1:5051/status
```

或使用 curl：

```powershell
curl.exe http://127.0.0.1:5051/status
```

接口会返回：

- 当前房间
- 当前阶段
- 连麦总次数
- 已用正式连麦次数
- 剩余正式连麦次数
- 超额批准次数
- 同批时间
- 在线成员
- 提醒批次

## 9. 当前版本注意事项

- 当前版本使用房间名 + 密码连接，暂未实现二维码/连接码。
- 当前版本为局域网本地服务器方案，不依赖公网。
- 选手悬浮件默认位于屏幕右上角，可拖动调整位置。
- 程序使用本地 TCP 通信，首次使用可能需要允许 Windows 防火墙访问。

# EmergencyLink 使用说明书

## 1. 软件文件

编译后的程序位于：

```text
dist\EmergencyLink.exe
```

同一个 exe 同时支持四种身份：

- 管理者
- 主办方
- 选手-比赛
- 选手-队友

## 2. 部署模式

### 模式 A：主办方电脑兼服务器

适合常规比赛现场。

主办方电脑负责：

- 启动本地服务器
- 创建房间
- 切换比赛阶段
- 审批正式连麦请求
- 扣减连麦次数

其他电脑连接主办方电脑显示的服务器地址。

### 模式 B：管理者电脑兜底服务器

适合主办方不熟悉软件，或需要技术人员统一控场时使用。

管理者电脑负责：

- 启动本地服务器
- 创建房间
- 配置次数和批次时间
- 切换比赛阶段
- 查看全量日志
- 必要时代替主办方审批

主办方电脑只需要作为“主办方”连接房间并审批请求。

## 3. 启动服务器

在需要作为服务器的电脑上打开 `EmergencyLink.exe`。

在“本机服务器”区域填写：

- 房间名
- 房间密码
- 端口，默认 `5050`
- 连麦次数，默认 `3`
- 同批时间，默认 `30` 秒

然后点击其中一个按钮：

- `主办方电脑兼服务器`
- `管理者兜底服务器`

启动成功后，界面会显示本机服务器地址，例如：

```text
192.168.1.20:5050
```

服务器启动后，房间名、密码、端口等启动参数会锁定。需要修改房间名或密码时，请先点击 `停止服务器`，修改后重新启动服务器。

其他电脑连接时需要填写这个地址、端口、房间名和房间密码。

如果其他电脑无法连接，请检查：

- 所有电脑是否在同一个局域网
- Windows 防火墙是否允许该程序或端口通信
- 填写的 IP、端口、房间名、密码是否一致

## 4. 主办方/管理者使用说明

主办方或管理者加入房间后，主要使用“管理/审批”页。

### 阶段切换

可切换四个阶段：

- 准备中
- 赛前测试
- 比赛中
- 结束比赛

规则：

- 赛前测试阶段允许测试提醒，不扣次数。
- 比赛中关闭测试通讯，只允许正式告警。
- 结束比赛后不应再发起新提醒。

### 配置调整

可随时调整：

- 连麦次数
- 同批时间

调整后点击 `应用配置`。

同批时间用于合并队友短时间内的重复提醒。例如设置为 30 秒时，同一目标选手在 30 秒内收到的同类提醒会合并为同一批次，但会再次触发动画和声音。

### 审批正式请求

比赛中，队友发起正式告警后，主办方/管理者会在“提醒批次”列表中看到请求。

选择请求后点击：

```text
同意选中正式请求
```

同意后规则：

- 剩余次数大于 0：已用次数 +1，剩余次数 -1。
- 剩余次数等于 0：记录为超额批准，剩余次数保持 0。

如果管理者审批，会在日志中记录为“管理者代审批同意”。

## 5. 选手-比赛使用说明

选手电脑打开 `EmergencyLink.exe`，在“连接房间”区域填写：

- 服务器地址
- 端口
- 房间名
- 房间密码
- 显示名称
- 角色：`选手-比赛`

连接成功后可进入“选手端”页。

比赛时建议：

- 主窗口可以最小化。
- 保留透明置顶悬浮件。
- 悬浮件默认点击穿透，不抢鼠标焦点。
- 收到提醒后使用 `Ctrl + Alt + R` 发送回执。

提醒样式：

- 测试提醒：蓝色/黄色闪烁 + 声音。
- 正式告警：红色闪烁 + 声音。
- 超额紧急请求：红色闪烁，并显示超额提示。

## 6. 选手-队友使用说明

队友电脑打开 `EmergencyLink.exe`，在“连接房间”区域填写连接信息，角色选择：

```text
选手-队友
```

连接后进入“队友端”页。

操作步骤：

1. 选择目标选手。
2. 赛前测试阶段点击 `确认发送测试提醒`。
3. 比赛中点击 `确认发起正式告警`。
4. 弹出二次确认窗口后，再点击确认。

队友端不能输入自由文本，只能触发预设提醒。

## 7. 日志

日志文件保存在 exe 同级目录的：

```text
Data\audit-yyyyMMdd.log
```

日志会记录：

- 服务器启动
- 成员加入/离线
- 阶段切换
- 配置调整
- 测试提醒
- 正式告警
- 提醒合并
- 选手回执
- 主办方同意
- 管理者代审批
- 超额批准

## 8. 当前版本注意事项

- 当前版本使用房间名 + 密码连接，暂未实现二维码/连接码。
- 当前版本为局域网本地服务器方案，不依赖公网。
- 选手悬浮件默认位于屏幕右上角。
- 程序使用本地 TCP 通信，首次使用可能需要允许 Windows 防火墙访问。
